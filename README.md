# pt_qb

Android app for managing qBittorrent (Web API v2), with PT site search & one-click push planned later.

## Features (planned)

- Multiple qB server configs, switch active server
- Torrent list: status filter, auto refresh, global transfer speed
- Torrent actions: pause / resume / delete (with files)
- Add magnet / URL / .torrent file
- (Later) PT site aggregated search + push to qB
